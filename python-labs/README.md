## ⚡ Golden Rules of Python (Quick Cheatsheet)

1. **Indentation is Everything**: Blocks of code are defined by whitespace (standard: 4 spaces), not curly braces `{ }`.
2. **No Semicolons Required**: Statements end with line breaks; no trailing `;` needed.
3. **Comments Use `#`**: Single-line comments start with `#`. Multi-line strings (`"""`) serve as docstrings.
4. **Dynamic & Strongly Typed**: Variable types are inferred at runtime, but Python does not implicitly coerce incompatible types (e.g., `'5' + 5` raises `TypeError`).
5. **Readability Counts**: Python code is written to be clean and readable (*The Zen of Python* - `import this`).

## 🚀 Running Any Lab Script

Run any script using Python 3:

```bash
# On Windows (PowerShell / Command Prompt)
python <script_name>.py
```
